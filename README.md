# MusicDoll Blender

> **中文** | [English](README.en.md)

一个用于 Blender 的动画制作插件，用来帮助你把各种乐器的演奏动画装到角色身上。

## 它是怎么来的

我们之前给每种乐器都单独写了一个插件：吉他有吉他的插件，钢琴有钢琴的插件，小提琴又有小提琴的插件。

一开始这样做很直接，但用着用着就发现麻烦越来越多：

- 每种乐器都要重新做一遍"创建控制器、保存状态、生成动画、导入导出"这些事，代码重复得很厉害；
- 一个 Blender 文件里想放两个不同乐器的演奏者时，两套插件互不相认，很容易打架；
- 想给所有乐器加一个公共功能（比如修正手指骨骼），就得每个插件各改一遍。

所以我们决定换一种做法：**把所有的乐器都收进一个插件里**，由它统一来管理。这个插件就是你现在看到的 MusicDoll Blender。

它借鉴了我们在 Unreal 那边同一个名字的插件（MusicDoll）的思路：一个总框架负责公共部分，每种乐器作为其中一块，大家共用一套规则。

## 它是做什么的

简单说，MusicDoll Blender 可以帮你：

- **管理演奏者**：一个 Blender 文件里可以同时放好几个演奏者，吉他手、钢琴手、小提琴手都行。你可以从下拉菜单里随意切换当前在操作哪位，插件会自动记住每个人的骨骼、乐器、文件路径这些信息；
- **搭建控制器**：选好角色和乐器后，一键把整套控制用的物体创建出来，并且自动摆好层级、挂好父子关系。重复点也不会出乱子；
- **保存和读取状态**：把每个姿势（比如左手按住某个品、右手拨某根弦）存到角色的骨骼上，随时可以再读回来，方便反复调整；
- **导入导出数据**：把整理好的动作信息导出成文件（`.avatar` / `.violinist` / `.zheng_master` / `.drummer` / `.harpist` / `.wind` 等），交给我们的其他工具（Rust / Unreal 那边）继续用，也能把别人整理好的数据导回来；
- **生成动画**：读入动作数据文件，直接在 Blender 里给控制器和琴键打好关键帧，生成整套演奏动画；
- **提供小工具**：每种乐器都带一些实用工具，比如"修正手指骨骼"是所有乐器都能用的，"给吉他生成弦的变形形状"是吉他特有的，"给钢琴键做按下的变形形状"是钢琴特有的。工具都收在一个下拉菜单里，默认收起来，想用哪个选哪个，界面很干净。

## 现在支持哪些乐器

这个项目是分阶段合并进来的，目前已经包括 7 种乐器：

| 乐器 | 缩写 | 类型 | 说明 |
| ---- | ---- | ---- | ---- |
| FretDance（吉他） | FD | 移动乐器 | 民谣吉他 / 电吉他 / 贝斯，支持左手按品、右手拨弦、颤音摇杆 |
| KeyRipple（钢琴） | KR | 固定乐器 | 双手弹奏，支持黑键白键、高低把位 |
| ZhengDrift（古筝） | ZD | 固定乐器 | 21 弦，支持左右手状态、双脚、双线性映射、特殊朝向控制器 |
| BeatBloom（打击乐） | BB | 固定乐器 | 鼓组演奏，DrumKit 配置驱动，左右手 / 双脚 + 头部朝向 |
| HarpGlide（竖琴） | HG | 固定乐器 | 47 弦（可配置），踏板 / 竖琴倾斜 / 手部 / 头部姿势 |
| WindRise（管乐） | WR | 移动乐器 | 中式笛子 / 长笛 / 单簧管 / 萨克斯等，按 MIDI 音高保存状态 |
| StringFlow（小提琴） | SF | 固定乐器 | 4 弦，数字命名手指，"手在弓上"结构，三点定平面琴弦工具 |

所有乐器共用同一套公共机制（演奏者管理、状态存取、动画写入、导入导出、工具系统）。

## 怎么用

1. 安装：把 `src\` 目录改名成 `music_doll_blender` 后放进 Blender 的插件目录（比如 `Blender\5.0\scripts\addons\`）；也可以直接把 `src\` 目录压缩成 zip 拖进 Blender 的"偏好设置 → 插件"窗口自动安装；
2. 在 Blender 的"偏好设置 → 插件"里找到并启用 **MusicDoll Blender**；
3. 在 3D 视图右侧的侧边栏找到 **MusicDoll** 面板；
4. 在"角色选择器"里新建一个角色（名字 + 乐器类型 + 骨骼 + 乐器物体）；
5. 在对应乐器的子面板里点"Setup Objects"把控制器搭好，然后就能保存/加载状态、导入导出数据、生成动画了。

面板顶部是统一的"角色选择器 / 角色操作"区域，所有乐器共用；下面会根据当前演奏者的乐器类型，自动只显示对应的乐器子面板，以及一个可折叠的"工具"下拉菜单。

## 项目里都有什么

```
music_doll_blender/
├── src/             # 全部源代码（把此目录压缩成 zip 拖入 Blender 即可安装）
│   ├── __init__.py  # 插件入口，负责把公共部分和各乐器模块都装好
│   ├── common/      # 公共部分：所有乐器共用的规则和工具
│   │   └── tools/   # 公共工具（比如修正手指骨骼、骨骼/控制器映射）
│   ├── fret_dance/  # 吉他模块（Phase 1）
│   ├── key_ripple/  # 钢琴模块（Phase 2）
│   ├── zheng_drift/ # 古筝模块（Phase 3）
│   ├── beat_bloom/  # 打击乐模块（Phase 4）
│   ├── harp_glide/  # 竖琴模块
│   ├── wind_rise/   # 管乐模块
│   └── string_flow/ # 小提琴模块
├── docs/            # 项目说明文档（中/英）
└── music_doll_blender.zip  # 分发包（本地生成）
```

- **common/** 是公共框架，相当于所有乐器的"地基"：怎么认识演奏者、怎么管理集合和物体、怎么读写状态、怎么写动画、怎么导入导出，都在这层统一实现，每个乐器直接复用；
- **fret_dance/ … string_flow/** 是乐器模块，只放各自特有的东西：乐器的控制器布局、状态含义、导出格式、专属工具。
